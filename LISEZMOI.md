# Les Loisirs – Entente des Abers

Appli de l'équipe de hand loisir : matchs, sondages, repas, gâteaux, cagnotte.

- `docs/` : l'appli elle-même (publiée par GitHub Pages).
- `robot/` : le robot qui envoie les notifications (lancé toutes les 15 minutes par GitHub).
- `.github/workflows/robot.yml` : le réglage qui lance le robot.
- `regles-base-de-donnees.json` : les règles de sécurité à coller dans Firebase (Realtime Database → Règles).

Nouvelle saison : dans l'appli, Admin → « Choisir le PDF du planning ».
